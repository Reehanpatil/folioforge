# Folio Forge

Build a portfolio in 3 minutes.

Folio Forge lets you create a professional portfolio website without coding. Fill in your details, choose a design, and download a ready-to-use `index.html` file that you can host anywhere.

##  Features

-  Build a portfolio in minutes
-  12 beautiful templates
-  Live preview
-  Add your photo
-  Dark & Light mode
-  Download a ready-to-use `index.html`
-  No account required
-  Free to use
-  No watermark

##  How to Use

1. Open Folio Forge.
2. Fill in your personal details.
3. Select your favorite template.
4. Preview your portfolio.
5. Download the generated `index.html`.
6. Upload it to GitHub Pages, Netlify, Vercel, or any web hosting service.

##  Tech Stack

- HTML
- CSS
- JavaScript
